# Kling 2.5 director

Bind provider, exact endpoint, tier and generation mode before writing the executable request. Do not inherit Kling 2.6/3.0 or Seedance prompt conventions.

## Verified scope, September 25, 2026

Higgsfield `kling-video/v2.5-turbo/standard/image-to-video`: required prompt and image_url; duration 5 or 10; cfg_scale 0–1, default0.5; optional negative_prompt. No documented ending-image or audio control on this endpoint. Pro needs its own verified contract. Refresh prices before spending.

## Prompt approach

Use the starting image for appearance/staging. Describe visible performance and a feasible camera path. Concise action-plus-camera wording is a working approach, not a proven requirement that longer prompts fail. Avoid unnecessary anatomical instructions when ordinary acting direction communicates the intent. Match a side-tracking start image to a side-tracking shot; a doorway frame does not guarantee that camera transition.

Keep sound design in the edit for this Standard endpoint. Retain usable intervals when a later artifact can be cut; review the adjoining edit. Do not equate a successful job with usable motion.
